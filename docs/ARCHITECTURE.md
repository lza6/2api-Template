# 架构

模板把「上游差异」与「协议通用逻辑」严格分层，让你只改上游适配，不碰协议引擎。

## 分层

```
┌─────────────────────────────────────────────┐
│  客户端: OpenAI SDK / Claude Code / Cursor   │
└─────────────────────────────────────────────┘
                    │  OpenAI / Anthropic 协议
┌───────────────────▼─────────────────────────┐
│  协议层 (protocol/)  —— 通用，无需改          │
│   · openai_sse:  非流式 JSON + 伪流式 SSE     │
│   · anthropic_sse: 非流式 + Anthropic 事件流  │
└───────────────────▲─────────────────────────┘
                    │  纯文本
┌───────────────────┴─────────────────────────┐
│  桥接层 (api.rs)  —— 半通用                   │
│   · 路由 / 鉴权 / CORS / 请求抽取             │
│   · call_upstream / resolve_model  [★ PROVIDER]│
└───────────────────▲─────────────────────────┘
                    │  上游契约
┌───────────────────┴─────────────────────────┐
│  上游适配 (upstream.rs + models.rs)  [★]      │
│   · 端点/头/请求体/响应解析                   │
│   · 模型目录                                 │
└───────────────────▲─────────────────────────┘
                    │  HTTP
              ┌─────┴─────┐
              │  上游站点  │
              └───────────┘
```

## 关键设计

### 1. 伪流式（上游非流式时）

上游一次性返回完整文本。协议层把它切成字符块，按间隔逐帧下发 SSE：

```
上游 {response:"hello"}  →  protocol::char_chunks("hello", N)  →  data: {...}\n\n × K  →  [DONE]
```

首字延迟 = 上游响应时间；之后按 `pseudo_chunk_delay_ms` 匀速吐字。客户端体验接近真流式。

### 2. 错误映射

| 上游情况 | 网关响应 |
|----------|----------|
| 额度哨兵串 | `429 rate_limit_error`（不透传哨兵文本） |
| 空响应 | `502 upstream_error` |
| 非 2xx | `502 upstream_error` |
| 空 messages | `400 invalid_request` |

流式中的错误以**尾帧**表达（OpenAI `finish_reason:stop` / Anthropic `message_stop`），不中途断连。

### 3. 未知模型策略

`pass_through_unknown_models`：
- `true`（默认）：请求的模型不在目录里也透传上游（上游可能新增模型，目录滞后）
- `false`：回退到 `default_model`

### 4. 鉴权

- 未配置 `api_keys` → 仅本机放行（本地使用零配置）
- 配置后 → 强制校验 `Authorization: Bearer` 或 `x-api-key`

### 5. 双形态共享

JS 核心与本地 Rust 版**共享同一份 `docs/PROTOCOL.md`**。上游变更时改一处文档，
两处实现同步跟进。二者的行为不变量由 `docs/INVARIANTS.md` 保证一致。
